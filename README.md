# Student Record Management System

A simple web-based student record management system built with Flask and MySQL, designed for managing student information such as name, email, age, and course. This project uses XAMPP to host the MySQL database locally.

## Features

- View all student records
- Add a new student
- Edit existing student records
- Delete student records

## Technologies Used

- Python (Flask Framework)
- MySQL (via XAMPP)
- HTML, CSS (Bootstrap for UI)
- Jinja2 (Flask templating engine)
